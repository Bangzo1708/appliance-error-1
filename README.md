The funniest honest error message an appliance could show: a washing machine that gives up on a sock-rope jam and asks its owner to negotiate with it. One line, 108 characters, written deterministically to `/output/entry.txt` on every run. Three candidate variants were written and judged against the house criteria (funniest, most honest as a real fault, freshest, tightest wording); the sock-rope standoff won on all four.

## Run it

```sh
node main.ts
```
